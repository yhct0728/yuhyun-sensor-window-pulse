# 작업 보고서 - 정상범위(valid_min/max) 재도입 — 3축 모델, 입력+전송만

**날짜**: 2026-06-05
**Phase**: Phase 4 (백엔드 API) — 계약 재정의 (2차)
**작업자**: Claude Code
**소요 시간**: 약 35분

## 작업 목표

센서 백엔드 스펙(정상범위 재요구)에 맞춰, ADR-0014로 제거했던 valid_min/max 전송을 **입력+전송만** 다시 도입한다(판정은 백엔드 단독, 로컬 이상치 표시는 부활 안 함).

## 배경 — 같은 날 3번째 결정

- ADR-0013: 펄스가 valid_min/max 로컬 설정·이상치 표시·전송 (추가)
- ADR-0014: 백엔드가 계약 되돌림 판단 → valid_min/max 전면 제거, dead+level 두 축
- **ADR-0015 (이번)**: 센서 백엔드가 valid_min/max 를 *다시* 요구. 품질을 3축으로 명확히 구분 — ① 정상범위(글리치 1개 컷, 백엔드 판정) ② 고장(dead, 센서 통째) ③ 경보(level1/2, 프론트). 펄스는 **입력+전송만**, 판정은 백엔드.
