# 작업 보고서 - 정상범위 전체 적용(fill-down)

**날짜**: 2026-06-28  
**Phase**: Phase 4 (백엔드 API) 부속 UI 개선  
**작업자**: Claude Code  
**소요 시간**: 약 30분

## 작업 목표

채널마다 정상범위(하한/상한)를 일일이 입력하던 수고를, 한 행 값을 노드 전체 채널에 복사하는 fill-down 버튼으로 줄인다.

## 구현된 기능

- 정상 범위 섹션의 각 채널 행에 **전체 적용 버튼**(`CopyPlus`). 클릭 시 그 행의 하한/상한을 그 노드의 모든 채널에 복사(기존 값 덮어쓰기)
- 로컬 상태만 갱신 — 적용 후 검토하고 기존 "정상범위 저장" 버튼으로 백엔드 전송(흐름 불변)
- 둘 다 빈 행은 버튼 비활성(`disabled`), 하한>상한·비숫자는 기존 인라인 경고 그대로
- 적용 후 토스트 "N개 채널에 정상범위를 적용했습니다"
