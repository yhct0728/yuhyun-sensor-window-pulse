## 작업 완료 후 의무 절차

다음을 반드시 순서대로 수행하세요. 하나라도 실패하면 사용자에게 보고 후 중단:

### 1. 자체 검증
- npm start로 앱 실행
- 작업 화면의 모든 인터랙션 직접 확인
- DevTools 콘솔에 에러 없는지 확인
- 다크모드 라이트모드 둘 다 확인

### 2. Playwright 테스트
- 이번 작업의 검증 체크리스트를 Playwright 테스트로 작성
  - 파일: tests/{작업명}.spec.js
  - 각 체크리스트 항목 = 하나의 test() 블록
- 기존 테스트와 새 테스트 모두 실행: npm test
- 모든 테스트 통과 확인

### 3. 작업 보고서 작성
- docs/work-log/TEMPLATE.md 형식 따라서
- docs/work-log/YYYY-MM-DD-{작업명}.md 생성
- 모든 섹션 빠짐없이 채우기

### 4. CLAUDE.md 업데이트
- Phase 로드맵의 해당 항목 [x] 체크
- 알려진 이슈 갱신
- 새 파일 구조 반영

### 5. 최종 보고
사용자에게 다음만 보고:
- 검증 통과 / 실패 항목
- 발견된 이슈
- 다음 단계 결정사항
- 작업 보고서 파일 경로
