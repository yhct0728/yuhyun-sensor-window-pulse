# 작업 보고서 - 개발용 자동 등록 시드(PULSE_AUTOIMPORT)

**날짜**: 2026-06-29
**Phase**: Phase 1/3 부속 (테스트 도구)
**작업자**: Claude Code
**소요 시간**: 약 50분

## 작업 목표

더미 .txt 로 Pulse 를 테스트할 때, 외부 에이전트(Claude Cowork)가 GUI 클릭 없이
"파일 두고 → 명령 실행"만으로 노드 등록 + 임계치 설정까지 자동화되게 한다.

## 변경 사항

### 수정된 파일
- `src/lib/store.jsx`
  - 헬퍼 추가: `looksHeaderRow`/`stripHeaderRows`, `roundSig`, `deriveRangeFromRows`(샘플값→보수적 정상범위), `pickRepresentativeType`(채널 종류 다수결)
  - `autoImportFromFolder({deriveRanges,sendBackend})` 추가 — 감시 폴더 .txt 를 위저드와 동일 경로로 헤드리스 일괄 등록 + 임계치 자동 도출. 컨텍스트에 노출. (TDZ 회피 위해 `setChannelRange` 정의 뒤에 배치)
- `src/App.jsx` — 테스트 훅에 `?test=import` 분기(=`store.autoImportFromFolder()` 호출 + 요약 토스트). `showToast` import 추가
- `src/main.js` — `process.env.PULSE_AUTOIMPORT` 시 렌더러 URL/loadFile 에 `?test=import` 부착(dev/prod 모두)
- `tests/pulse-v2.spec.js` — 자동 등록 E2E 1개 추가
- `CHANGELOG.md` `[Unreleased] > Added` 항목 추가

### 추가된 파일

## 구현된 기능

- `PULSE_AUTOIMPORT=1 npm start` → 부팅 직후 감시 폴더의 모든 .txt 자동 등록(클릭 0)
- 채널/종류/단위는 `resolveSensors` 가 추론, 정상범위는 샘플 데이터에서 보수적 도출
- 형식 오류(🔴) 파일은 건너뜀(GUI 등록 게이트와 동일), 요약을 콘솔/토스트로 보고
- 백엔드 설정 시 노드/채널은 위저드와 동일 payload 로 전송(실패해도 로컬 등록 유지)

## 알려진 이슈
- 감시 폴더 스캔은 재귀 → 폴더 하위 모든 .txt 등록. 더미만 원하면 rootFolder 를 하위 더미 폴더로 지정.
- 영속성 없음(메모리) — 재시작 시 노드 휘발(Phase 2 SQLite 전까지 동일).
- 정상범위는 로컬 도출 보관까지. 백엔드로의 범위 전송은 드로어 "정상범위 저장" 시점(노드/채널 자체는 등록 시 전송).
