# 작업 보고서 - 경사계 2열 = 1대(X·Y) 쌍 묶기

**날짜**: 2026-10-12  
**Phase**: Phase 4~5 (백엔드 연동 · 동기화) 동작 수정  
**작업자**: Claude Code  
**소요 시간**: 약 40분

## 작업 목표

구조물 경사계 파일(값 4개 또는 6개)을 값 2개 = 경사계 1대(X·Y)로 등록하고 전송한다.

## 원인

기존 코드는 경사계 1대가 A0·A180·B0·B180 네 값을 낸다고 가정했다.

1. 4값 파일을 2대가 아니라 1대(1·2열 = X, 3·4열 = Y)로 묶었다.
2. 6값 파일은 5·6열을 경고 없이 버렸다.
3. 묶은 값을 `raw_channels` 로 보냈다. 백엔드 ingest 는 `value` 만 읽는다(백엔드 `main` 확인).

## 구현된 기능

- 4값열 → `BT-1-X`, `BT-1-Y`, `BT-2-X`, `BT-2-Y`. 6값열 → `BT-3-X`, `BT-3-Y` 까지.
- 값은 열마다 일반 `value` 로 전송한다. 백엔드 수정 없음.
- 등록 화면에 "경사계 N대로 등록합니다" 안내가 뜬다. 홀수 열이면 경고가 뜬다.
- 온도열은 쌍에서 뺀다. 채널 종류를 섞으면 묶지 않는다.

## 알려진 이슈

- 열 순서를 X1, Y1, X2, Y2… 로 가정했다. 실제 로거 파일로 확인하지 못했다.
- 옛 방식으로 등록된 경사계 노드는 삭제 후 다시 등록해야 한다. 삭제하면 그 노드의 서버 데이터도 지워진다.
- 서버와 웹은 X·Y 를 별개 센서로 본다. 묶음은 이름으로만 드러난다.
