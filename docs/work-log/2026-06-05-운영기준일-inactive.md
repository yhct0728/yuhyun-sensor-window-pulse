# 작업 보고서 - 운영 시작일(monitoring_from) 추가 + 생명주기 dead→inactive

**날짜**: 2026-06-05
**Phase**: Phase 4 (백엔드 API) — 센서 운영/품질 체계
**작업자**: Claude Code
**소요 시간**: 약 50분

## 작업 목표

센서 백엔드 "운영/품질 체계" 스펙 반영. ① 정상범위(기존 유지) ② 운영 시작 기준일 monitoring_from(신규) ③ 센서 고장 상태값 dead→inactive(변경).

## 변경 사항

### ② monitoring_from (신규)
- `backendApi.js` — `nodeRegisterBody` 에 `monitoringFrom`→`monitoring_from` 동봉(undefined=키 생략), 신규 빌더 `nodeMonitoringBody`(노드 단위 최소 본문), `normalizeBackendNode` 가 `monitoring_from` 읽어 복원
- `folderService.js` — `setMonitoringFromToBackend`(POST /nodes) + IPC `nodes:set-monitoring-from` + import
- `preload.js` — `setMonitoringFrom` 노출 / `folderApi.js` — `setMonitoringFromBackend`
- `store.jsx` — `buildNode` 에 `monitoringFrom`, GET 경로(`loadNodesFromBackend`)에서 복원, 신규 액션 `updateMonitoringFrom`(로컬 즉시 + 백엔드 POST), context 노출
- `NodeDetailDrawer.jsx` — 헤더에 "운영 시작일" date 입력 + `onChangeMonitoringFrom`(YYYY-MM-DD→`T00:00:00+09:00`, 빈값=null 해제) + `savingMon`
- `RegisterWizard.jsx` — "확인"(StepConfirm) 단계 date 입력 + `monitoringFrom` state, 등록 시 로컬 노드·백엔드 payload 동봉

### ③ dead → inactive (변경)
- `backendApi.js` — `SENSOR_LIFECYCLE` off 값 `dead`→`inactive`, `LIFECYCLE_LABEL` 에 inactive 추가(레거시 dead/disabled 는 흡수), 주석
- `NodeDetailDrawer.jsx` — `LifecycleSelect` off 값 `dead`→`inactive`
- `store.jsx`/`folderService.js`/`folderApi.js` — 주석·jsdoc 의 dead/disabled → active/inactive

### ① 정상범위
- 변경 없음(ADR-0015 그대로).

### 테스트 (`tests/pulse-v2.spec.js`)
- 추가: `nodeRegisterBody` monitoring_from 동봉/생략, `nodeMonitoringBody` 최소 본문, 드로어 운영시작일 입력→`setMonitoringFrom`(ISO/KST)
- 변경: 생명주기 테스트 전송값 `dead`→`inactive`
