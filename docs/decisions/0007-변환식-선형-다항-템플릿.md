# 0007. 변환식(선형/다항) 템플릿 층 추가 — 노드별 전환 가능

- 상태: [ADR-0008](0008-계측기-종류-마스터-종류공식-센서보정.md) 로 대체됨 (공식이 종류 레벨 expression 으로 이동)
- 날짜: 2026-05-25
- 결정자: 사용자 / Claude Code
- 관련: [ADR-0006](0006-노드-채널별-보정값.md), `src/lib/calibration.js`, `CalibrationModal.jsx`, `DataChart.jsx`

## 맥락

ADR-0006 에서 변환식(raw→물리값)은 계수 출처가 미정이라 보류했었다. 이후 사용자가 칼리브레이션 시트 정보를 제공:

- 시트에 **팩터값 + 하단 계산식**이 있고, 형태는 두 가지:
  - 선형: `G·(R₁ − R₀) + k·(T₁ − T₀)`
  - 다항: `A·R² + B·R + C + k·(T₁ − T₀)`
- **측정온도(T₁)는 원본 데이터에 안 들어와서 열보정 항 `k(T₁−T₀)`는 0 으로 처리**하기로 함.
- 우려: 같은 계측기 종류라도 시트(개체)마다 계산식이 다를 수 있음.

## 결정

- `calibration.js` 에 **변환식 템플릿** 도입 (열보정 제외 형태):
  - 선형: `y = G·(R − R₀)` (팩터 G, R₀)
  - 다항: `y = A·R² + B·R + C` (팩터 A, B, C)
- 채널 보정 설정을 `{ template, params, offset }` 로 통합. **최종 = 변환식(R) + 보정값(±)**.
- **기본 템플릿 = 선형**, 기본 팩터는 항등(G=1, R₀=0)이라 입력 전엔 원본 그대로. **노드(채널)마다 다항으로 전환 가능** — 변환식을 계측기 종류에 고정하지 않음으로써 "같은 종류라도 시트마다 다른" 경우를 흡수.
- 팩터는 칼리브레이션 시트를 보고 **채널별로 입력**. 모달에 [변환식 선택 + 팩터 입력] 추가, 라이브 최종값.
- 열보정 항은 측정온도 미수신이라 **제외(0)**. 추후 온도 채널이 생기면 템플릿 한 줄 추가로 확장.

## 결과

- 좋은 점: 시트의 두 계산식을 그대로 적용. 변환식이 노드별이라 종류 내 변동에 강함. 새 계산식 형태가 나오면 `FORMULA_TEMPLATES` 에 함수 하나 추가로 끝(재설계 불필요).
- 트레이드오프:
  - 다항은 **절대형 `A·R²+B·R+C`** 로 구현. 시트가 상대형 `(AR₁²+BR₁+C)−(AR₀²+BR₀+C)` 이면 템플릿 추가 필요.
  - **열보정 미구현**(온도 미수신). 온도 채널 도입 시 확장.
  - 보정 설정 **영속 X**(ADR-0006 과 동일, NodeDetail 로컬 상태 → Phase 2 SQLite/sites).
- 검증: 변환식 수학 단위 10/10(선형·다항·오프라인 보존·영점·채널별 적용), 모달 캡처(선형 기본 → 다항 전환), 콘솔 에러 0.

## 대안

- **변환식을 계측기 종류에 고정** — 같은 종류라도 시트마다 다르면 깨짐. 기각(노드별 + 종류는 기본 추천만).
- **자유 수식 입력** — 오타·보안(eval) 위험. 템플릿 + 팩터로 한정.
