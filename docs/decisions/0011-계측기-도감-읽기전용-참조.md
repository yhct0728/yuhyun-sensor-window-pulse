# 0011. 채널 정의 → 계측기 도감(읽기 전용 참조 페이지)로 교체

- 상태: 채택됨 (ADR-0010 의 "채널 정의" 페이지 부분을 대체)
- 날짜: 2026-05-29
- 결정자: 사용자 / Claude Code
- 관련: 사용자 핸드오프(원본 `yuhyun-sensor-front` `/reference`), ADR-0009·0010; 신규 `lib/sensorReference.js`, `pages/Reference.jsx`, `components/reference/{SensorListTab,FormulaTab,CoefficientTab,sensorIcons,referenceColors}.{jsx,js}`; 삭제 `pages/Channels.jsx`, `components/channels/*`

## 맥락

ADR-0010 의 "채널 정의" 페이지(사용자가 채널 타입을 추가/관리하는 빈 카탈로그→시드 도감)를, 사용자가 GeoMonitor 의 **계측기 도감** 페이지(`/reference`)로 교체 요청. 도감은 **22종 계측기 · 5종 측정 공식 타입 · 공식 계수 사전**을 정보 전달용으로 보여주는 **순수 읽기 전용** 단일 페이지(API·상태·로그인 없음). 데이터는 정적 파일 하나(`sensor-reference.ts`)가 단일 소스.

쟁점: 이 도감은 공식·계수를 다시 화면에 들인다 → ADR-0009(공식/보정 개념 제거)와 충돌하는가? **아니다.** Pulse 는 여전히 공식을 *적용·계산하지 않는다*. 도감은 "어떤 계측기가 어떤 공식·계수로 환산되는가"를 사람에게 **설명하는 문서**일 뿐이며, 런타임 데이터·전송 페이로드와 무관하다(현장-블라인드 §0 도 위반 아님 — 현장·안전 판정 없음).

## 결정

- "채널 정의" 페이지·컴포넌트(`Channels`/`AddTypeModal`/`ChannelTypeDetail`) 제거, 사이드바 메뉴를 **계측기 도감**(`reference`)으로 교체.
- 원본 7파일을 Pulse 스택(React + Tailwind + JSX)으로 이식:
  - `sensor-reference.ts` → `lib/sensorReference.js` (데이터 **1:1, 한 글자도 변경 없음**: CATEGORIES/SENSORS 22/FORMULAS 22/FORMULA_DEFS 5).
  - `sensorIcons.tsx` → `sensorIcons.jsx` (stroke 인라인 SVG 14종, path 동일).
  - 3탭(SensorList/Formula/Coefficient) + page → `components/reference/*` + `pages/Reference.jsx`.
  - CSS Modules + `oklch(from …)` 상대색 → **Tailwind 색군 매핑**(§6 폴백: water=sky·construction=rose·slope=amber·weather=teal·facility=violet, 공식타입/출처도 동일 패턴). `referenceColors.js` 한 곳에 정의.
- 도감은 PageHeader(다크 토글) 아래 밑줄형 3탭 + `key`로 탭 페이드(.2s).

## 결과

- 사용자가 계측기·공식·계수를 한 화면에서 열람(필터/서브탭). Pulse 는 여전히 원본 전달만(공식 미적용) — 도감은 문서.
- `lib/channelCatalog.js` + store `channelTypes` 는 **등록 위저드의 채널 코드 자동완성용으로 유지**(GI/BT… 코드 사전). 도감(sensorReference)과는 별개 — 도감은 한글명 기준이라 코드 매칭에 부적합.
- 검증: E2E 11/11(채널 빈상태 테스트 → 도감 3탭 검증으로 교체), `npm start` 5173 클린 기동(캐시 에러 0), 빌드 OK.

## 대안

- **별도 "계측기 도감" 메뉴 추가 + 채널 정의 유지** — 유사 페이지 2개로 중복. 사용자가 **교체** 선택.
