# 0002. 감지된 파일 행 전체를 선택 토글 영역으로 확대

- 상태: 채택됨
- 날짜: 2026-05-25
- 결정자: 사용자 / Claude Code
- 관련: `src/components/dashboard/DetectedFileRow.jsx`, [CHANGELOG.md](../../CHANGELOG.md)

## 맥락

대시보드 "감지된 파일" 목록에서 선택 토글이 좌측 18px 체크박스에서만 동작했다. 클릭 타깃이 좁아 선택이 번거로웠다. 사용자가 "행 컴포넌트 전체를 누르면 체크되도록 이벤트 타깃을 넓혀달라"고 요청.

## 결정

`DetectedFileRow` 바깥 `div` 에 `onClick` 으로 토글을 걸어 **행 전체를 클릭 타깃**으로 만든다. 단, 행 안의 인터랙티브 요소는 자체 동작을 유지한다:

- 체크박스·"등록" 버튼 래퍼에 `stopPropagation` → 행 클릭과 겹쳐 **이중 토글로 상쇄되는 버그**를 막고, "등록" 클릭이 선택을 토글하지 않게 한다.
- 이미 등록된(`isRegistered`) 행은 토글 비활성 (클릭 무반응).
- 미등록 행에만 `cursor-pointer select-none` 부여 (클릭 가능 표시 + 텍스트 드래그 방지).

## 결과

- 좋은 점: 선택이 훨씬 쉬워지고, 클릭 영역과 등록 버튼의 책임이 명확히 분리됨.
- 트레이드오프: 행 안에 클릭 동작이 두 종류(토글 vs 등록) 공존 → `stopPropagation` 규칙을 깨면 회귀 위험. ADR로 의도를 남겨 둠.

## 대안

- **체크박스만 유지** — 요청 불충족.
- **행을 `<button>` 으로** — 내부에 버튼(체크박스·등록)이 중첩돼 잘못된 HTML. div + onClick 로 회피.
