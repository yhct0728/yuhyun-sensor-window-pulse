# 0020. "마지막 수신"의 정본을 파일 안 데이터 시각으로 삼는다

- 상태: 채택됨
- 날짜: 2026-08-22
- 결정자: 사용자 / Claude Code
- 관련: [ADR-0019](0019-수집주기-단일출처-기록간격-용어분리.md), `src/folderService.js`, `src/lib/store.jsx`

## 맥락

사용자 최초 문의: **"메모장에서 끊긴 시점과 화면의 마지막 수신 날짜가 일치하지 않는다."**

추적 결과 `lastRx` 의 출처가 경로마다 달랐다.

| 경로 | 들어가던 값 |
|---|---|
| 등록 위저드 / 자동 임포트 | 파일 저장시각(OS mtime) |
| 백엔드 복원 | 백엔드 `last_seen` |
| 전송 성공 직후 | 데이터 행의 마지막 시각 |

기본값이 mtime 이라는 게 핵심 결함이다. 타사 로거는 파일을 **덮어쓰기**하므로 데이터가 끊겨도 mtime 은 갱신된다 → **끊긴 노드가 "수신중"으로 보인다.** 알림을 놓치는 방향의 오류라 더 위험하다.

여기에 두 번째 못이 있었다. `syncNode` 는 신규 행이 없으면 조기 return 하므로, 끊긴 노드는 등록 당시 값에 영구히 박제된다.

실측으로도 확인됐다. 로컬 `80053.txt` 는 데이터가 2026-06-01 까지인데 파일 저장시각은 그 이후이고, 백엔드 `last_seen` 은 2026-08-10 이었다. 백엔드의 노드 생성일이 7/24 이므로 **8월 데이터는 이 파일에서 간 것이 아니다** — 타사 PC 가 같은 `node_code` 로 전송 중이다.

## 결정

**Pulse 는 수집기다. 자기 파일에 무엇이 들어왔는지를 보고한다.**

1. `lastRx` = **감시폴더 파일 안 마지막 데이터 행의 시각**(`periodEnd`). 한 줄도 없으면 `null`(미상).
2. `lastFileWrite` = 파일 저장시각(mtime). **분리 보존하고 화면에 함께 표시**한다.
3. **매 스캔마다 갱신**한다. 전송 성공에만 의존하지 않는다.
4. 내 파일이 있으면 **내 파일이 백엔드 `last_seen` 보다 우선**. 내 파일이 없는 노드(타사 담당)만 백엔드 값으로 폴백.
5. **`periodEnd` 가 없다고 mtime 으로 때우지 않는다.** 그게 원래 버그였다.

전송 워터마크(`lastSentTs`)는 그대로 백엔드 `last_seen` 을 쓴다 — 그건 "어디까지 보냈나"라는 다른 개념이다.

### 두 값을 함께 보여주는 이유

차이 자체가 진단이다.

```
마지막 데이터  5/20 14:00     ← 센서가 실제로 준 값
파일 저장     오늘 09:12      ← 로거가 파일을 건드린 시각
```

- **둘 다 옛날** → 로거가 멈춤
- **파일 저장만 최신** → 로거는 도는데 센서 값 유입이 끊김

노드 상세의 진단 로그가 후자를 문장으로도 짚어준다.

## 결과

**좋은 점**

- 끊긴 노드가 끊긴 것으로 보인다. 알림의 전제가 성립한다.
- 값의 출처가 하나로 통일됐다.
- 보낼 게 없는 노드도 시각이 갱신된다.
- "로거 사망 vs 센서 사망"을 화면에서 바로 가른다.

**트레이드오프**

- 매 스캔마다 파일 전체를 훑어 마지막 유효 행을 찾는다. 덮어쓰기 로거라 파일이 커지지 않는다는 전제 위에 있다. 누적형 파일이 유입되면 역방향 부분 읽기로 바꿔야 한다.
- 데이터가 없는 파일은 "미상"이라 끊김으로 표시된다. 정확하지만, 신규 설치 직후에도 그렇게 보인다.

**후속**

- 전 노드의 기록 간격이 1440분(위저드 기본값)이라 판정 임계가 36시간/72시간이다. 실제 간격으로 조정해야 알림이 제때 뜬다.
- 전송 타임스탬프에 시간대 표기가 없다(`toIso` 가 벽시계 유지). 백엔드 확인 필요 — 미해결.

## 대안

- **백엔드 `last_seen` 을 정본으로.** 시스템 전체가 아는 값이라 일관되지만, 타사 PC 가 채운 값이면 *이 수집기* 의 상태를 감춘다. 80053 이 정확히 그 경우다.
- **둘 중 최신값 사용.** 항상 "더 최근"이라 안심되지만, 그게 바로 끊김을 감추는 방향이다.
- **mtime 폴백 유지.** 화면에 빈칸이 안 생기지만, 원래 버그를 남기는 선택이다.
