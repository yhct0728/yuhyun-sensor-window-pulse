# 결정 기록 (ADR)

이 폴더는 **의미 있는 결정**만 한 건당 한 파일로 남깁니다. ([Architecture Decision Records](https://adr.github.io/) 방식)

## 왜 이렇게 하나

- **타팀 보고**가 목적 — "무엇이 바뀌었나"는 [CHANGELOG.md](../../CHANGELOG.md), **"왜 그렇게 정했나"는 여기**.
- 결정 1건 = 짧은 파일 1개. 길어져도 **이 인덱스만 훑고 필요한 1건만** 펼치면 됩니다.
- 기록은 **고치지 않습니다.** 결정이 바뀌면 기존 파일의 상태를 `폐기됨` 또는 `NNNN로 대체됨`으로 바꾸고 **새 ADR**을 추가합니다. (히스토리 보존)

## 새 결정 추가하기

1. `adr-template.md` 를 복사해 `NNNN-짧은-제목.md` 로 만든다 (`NNNN` = 다음 번호, 4자리).
2. 맥락·결정·결과·대안을 채운다.
3. 아래 인덱스에 한 줄 추가한다.
4. 사용자에게 보여줄 변경이면 [CHANGELOG.md](../../CHANGELOG.md) `[Unreleased]` 에도 한 줄 적고 이 ADR을 링크한다.

> 무엇이 "의미 있는 결정"인가: 방향·구조·UX를 바꾸는 선택, 트레이드오프가 있는 선택, 나중에 "왜 이렇게 했지?" 가 나올 만한 선택. 오타·리네이밍·단순 버그픽스는 제외(그건 CHANGELOG의 Fixed 한 줄로 충분).
