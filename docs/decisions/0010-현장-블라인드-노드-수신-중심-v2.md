## 맥락

v2 핸드오프가 Pulse 의 역할을 **"현장-블라인드"** 로 재정의했다. Pulse 는 현장(Site)을 알지 못하고, **노드(장비 ID) 단위로만** 로우데이터를 수신·적재·전송한다. 다루는 상태는 **수신(reception) + 전송(transmit)** 뿐이며, **안전 판정(정상/의심/오류)과 현장 stamp 는 백엔드(GeoMonitor)** 책임이다. 전송 페이로드는 `{ nodeId, channel, ts, value }` 로 **현장 필드가 없다**. 모든 런타임 데이터는 **제로 디폴트(빈 배열)** 로 시작한다.

기존 v1 은 현장→노드→센서 계층 + 안전 판정 + 공식/보정 잔재를 갖고 있어 원칙과 충돌했다. 시각 기준 프로토타입은 **로더 HTML 만 전달**되고 본문 JSX(`pulse2-*.jsx`)가 누락되어, 구현은 **텍스트 사양 + HTML head 디자인 토큰 + v1 디자인 시스템(zinc/1px/에메랄드)** 으로 진행했다(사용자 승인).

## 결정

- **현장 개념 전면 제거**: 현장 등록/선택/매핑 UI·`siteCode`·`SITE_CATALOG`·`sensor_positions` 제거. 어떤 타입에도 현장 필드 없음.
- **안전 판정 제거**: `anomalyDetection`·`STATUS_LABEL(정상/의심/오류)`·`Badge.StatusPill` 삭제. 상태는 `reception(live/delayed/lost)` + `transmit(sent/queued/retry/failed)` 만(`lib/reception.js`).
- **공식/보정 잔재 제거**: ADR-0009 에서 시작한 정리를 마무리(`sensorTypes`·`formula*`·`coefficient*` 삭제). 채널 "타입"은 의미 사전(`ChannelType`)으로만 존재(`Channels` 페이지).
- **페이지 재구성**: `노드 모니터`(모니터링/감지·등록 탭 + 우측 노드 상세 드로어 + 4단계 등록 위저드) · `전송 큐` · `채널 정의` · `진단 로그`/`설정`(플레이스홀더). 라우터 없이 `App.jsx` `page` state.
- **상태 저장소**: `lib/store.jsx` React Context(useState). 제로 디폴트. Phase 1 = 메모리.
- **실제 IPC**: `folder:*`(재사용) + 신규 **`files:analyze`**(인코딩/행수/구분자/열수/주기추정/미리보기). 노드/인제스트/채널 CRUD 는 렌더러 메모리 + IPC TODO 주석.

## 결과

- Pulse 가 "현장 모니터"가 아니라 **노드 단위 수집·전송 파이프**임이 코드로 명확. 데이터 흐름: 타사 → .txt(워치 폴더) → Pulse(노드 ID 기준 원본 전달) → 백엔드(현장 stamp·안전 판정) → 웹.
- v1 화면(Dashboard/Settings/NodeDetail/SensorTypes)·컴포넌트·lib 대량 삭제. 재사용: `ui/{Modal,Button,Select,Checkbox,Avatar,Toggle,Sparkline,Toast}`, `hooks/{useDarkMode,usePolling}`, `folderService.js`, `globals.css` 토큰.
- 잔여: 노드/채널/전송은 메모리(Phase 1, 재시작 시 휘발). 인제스트 미연결(제로 디폴트). `recharts`·`mathjs` 미사용 의존성(정리 가능). 검색(⌘K)·진단 로그/설정 페이지는 추후.
- 검증: Playwright E2E **11/11**(빈상태 5종·5메뉴 네비·위저드 4단계·드로어 3탭·다크·콘솔에러0), 헬퍼 단위 12/12(inferNodeId·classifyChannel·receptionOf), `npm start` 기동·메인 콘솔 에러 0, 현장-블라인드 회귀 grep(현장/안전판정 식별자는 원칙 주석에만 잔존).
