# 0003. 일괄 등록 액션을 하단 플로팅 토스트 바로 전환

- 상태: 채택됨
- 날짜: 2026-05-25
- 결정자: 사용자 / Claude Code
- 관련: `src/components/dashboard/DetectedFilesPanel.jsx`, [ADR-0002](0002-감지파일-행-전체-클릭-토글.md)

## 맥락

기존엔 파일을 1개 이상 선택하면 리스트 **상단에 인라인 액션 바**가 끼어들어 레이아웃을 밀었다. 사용자가 "선택하면 등록 버튼이 토스트 형태로 떠오르고, 누르면 일괄 등록 팝업이 나오게" 해달라고 요청.

## 결정

선택 개수가 1 이상일 때 **화면 하단 중앙에 토스트 형태의 플로팅 바**를 띄운다.

- 구성: `N개 선택됨` · `해제`(선택 비우기) · **`일괄 등록`** 버튼.
- `일괄 등록` 클릭 → 기존 `onBulkRegister` 호출 → 기존 `BulkRegisterModal` 팝업 (등록 흐름 자체는 변경 없음).
- 색·그림자는 기존 `Toast` 컴포넌트와 동일 톤(`bg-zinc-900`/다크 반전 + `shadow-xl`), 진입은 `pulse-fade`.
- `z-40` 으로 모달(`z-50`)보다 아래 → 모달이 열리면 백드롭이 바를 덮음.
- 플로팅 바를 패널 루트의 **형제**로 분리 → 패널 진입 애니메이션의 `transform` 이 `position: fixed` 기준점을 가로채는 문제 방지.

## 결과

- 좋은 점: 리스트가 밀리지 않고, 선택-등록 동선이 자연스러움. 등록 로직은 그대로라 위험 낮음.
- 트레이드오프: 화면 하단 우측 알림 토스트(`ToastHost`, `z-50`)와 위치·역할이 다르므로(하단 중앙 vs 우하단) 혼동되지 않게 유지해야 함.

## 대안

- **인라인 액션 바 유지** — 요청 불충족, 레이아웃 밀림.
- **헤더 고정 바** — 리스트와 멀어 선택 맥락이 약함. 하단 플로팅이 선택 작업과 더 가까움.
