# 0006. 노드 값에 채널별 ± 보정값 도입 (변환식은 추후)

- 상태: [ADR-0008](0008-계측기-종류-마스터-종류공식-센서보정.md) 로 대체됨 (공식이 종류 레벨로 이동, 센서는 offset/scale)
- 날짜: 2026-05-25
- 결정자: 사용자 / Claude Code
- 관련: `src/lib/calibration.js`, `components/node-detail/CalibrationModal.jsx`, `NodeDetail.jsx`, `DataChart.jsx`, `App.jsx`

## 맥락

노드 값에 보정이 필요한데, 사용자 정의상 **"보정값 = 플러스마이너스 얼마"** 수준의 단순 ± 오프셋이다(게이지팩터·다항 같은 복잡 계수 아님). 변환식(raw→물리값, 종류별 템플릿)은 계수 출처가 아직 미정이라 이번엔 보류. 노드는 채널(v1/v2/v3) 다수 구조이고, 원본 .txt 는 불변이어야 한다.

## 결정

- `src/lib/calibration.js`: 채널별 `offsets` 를 측정값에 더하는 `applyCalibration(rows, cal)`. **최종 = 측정값 + 보정값**(변환식 자리는 비워둠 — 추후 이 앞에 삽입). **오프라인(0)은 보정 제외**(이상치 offline 규칙 보존).
- `CalibrationModal`: 채널 표(현재값 → 보정 ± → 최종 라이브), **"모든 채널 같은 값"** 토글(한번에 적용), **채널별/전체 "현재값으로 영점"**. 현재값 = 최근 유효(비영) 값.
- `NodeDetail`: 보정 적용 결과가 차트·테이블·센서카드·이상치 판정에 모두 반영. **원본값/적용값 토글** 추가. 노드 전환 시 `App` 에서 `key={node.id}` 로 재마운트(보정/필터 상태 초기화).
- `DataChart`: 글리치 매핑을 **절대 임계값(`<5000`) → 데이터 상대(중앙값 ± MAD×8)** 로 변경. 보정으로 스케일/부호가 바뀌어도 정상 대역에 Y축이 집중되고, spike 는 마커로 유지. (보정값 적용 시 차트가 비어버리던 문제 해결)

## 결과

- 좋은 점: 사용자가 원한 단순 ± 보정이 채널별·일괄로 동작하고, 전 표시(차트/테이블/카드/이상치)에 일관 적용. 원본 보존. 차트가 어떤 스케일에서도 정상 대역에 집중.
- 트레이드오프:
  - **영속 X** — 보정값은 `NodeDetail` 로컬 상태라 화면을 떠나면 휘발(노드 재마운트). 추후 `sites`/SQLite(Phase 2)에 저장 필요.
  - **변환식(raw→물리값)은 미구현** — 계수 출처(센서 스펙 vs 입력) 확정 후 이 위에 한 층 추가.
  - "모든 채널 같은 값"은 초기 보정이 전부 0(동일)이라 기본 ON 으로 열림.

## 대안

- **자유 수식 / 복잡 계수 입력** — 사용자가 ± 만 원함. 기각(과설계).
- **DataChart 절대 임계값 유지** — 보정 적용 시 값이 5000 미만이면 차트가 빈다. 기각.
