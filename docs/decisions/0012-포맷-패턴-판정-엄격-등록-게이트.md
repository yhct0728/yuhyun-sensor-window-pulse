# 0012. 로거 포맷 패턴 판정 + 등록 게이트(권장/느슨)

- 상태: 채택됨
- 날짜: 2026-05-30
- 결정자: 사용자 / Claude Code
- 관련: `lib/formatClassify.js`(신규), `lib/series.js`, `folderService.buildDetectedFile`(header/sampleRow 추가), `folderApi.scanFolder`, `components/nodes/{DetectedFileRow,RegisterWizard}.jsx`

## 맥락

로거가 떨구는 .txt 는 통상 4가지 패턴으로 귀결된다: **번호형(`1,2,3`) · 이름형(`GI-A`) · 깊이형(`0.0M…`, 어레이형 계측기) · 값+온도형**. 컬럼 모양은 "센서 종류"가 아니라 **로거 프로그램 설정**이 정하므로 미리 알 수 없다. 사용자 요청: 파일이 무슨 형인지 추론해 UI로 보여주고, **패턴/형식이 멀쩡하지 않으면 애초에 노드 승격을 막자**.

쟁점은 "막는 기준". "4패턴 중 하나냐"로 막으면 번호형·이름형이 사실상 통짜 범주라 거의 안 걸리고, 정작 막아야 할 건 **표 자체가 깨진 파일**(시각 열 없음·값 열 없음·열 수 불일치)이다. 그리고 사용자는 "주의(파싱되나 비정형)"도 차단하는 **엄격 모드**를 택했다.

## 결정

- **판정기 `classifyFormat(header, sampleRow)`** → `{status, pattern}`:
  - `error` 🔴 — 표가 아님(열<2 · 첫 열이 시각 아님 · 값 열 없음)
  - `warn` 🟡 — 파싱되나 비정형(제목 일부 누락 · 헤더/데이터 열 수 불일치 · 패턴 불명)
  - `ok` 🟢 — 표 멀쩡 + 패턴 인식(depth/valuetemp/numbered/named). 깊이형은 `detectSeries` 재사용.
- **게이트(권장/느슨)**: `status !== 'error'` 면 등록 허용 — 즉 `ok`(정상) + `warn`(비정형, 경고 표시 후 허용). `error`(표가 깨짐: 열 1개 이하)만 차단.
  - > 처음엔 "엄격(ok만 허용)"으로 갔으나 정상 파일까지 막혀(시각 형식 다양성·열 불일치 등) **같은 날 느슨으로 전환**. 미출시 churn. `error`는 "시각열 없음"을 빼고 "값 열 자체가 없음(열<2)"만 남겨 `isDateLike`(-, /, . 형식 폭넓게)로 완화.
- **메인에서 헤더 제공**: `buildDetectedFile` 가 앞 2줄(제목+첫 데이터)을 파싱해 `header`/`sampleRow` 반환 → 렌더러 `scanFolder` 가 `classifyFormat` 부착(목록에서 바로 판정).
- **UI**: 감지 목록 행에 패턴 뱃지(🟢 중립 / 🟡 앰버 / 🔴 레드) + 비-ok 는 "등록 불가" 비활성 버튼 + 사유. 등록 위저드 분석 단계에도 동일 판정 배너 + 게이트(다음 차단).

## 결과

- 사용자가 파일별로 "번호형/깊이형/형식 오류" 를 한눈에 보고, 깨진 파일은 등록 자체가 막힘 → 잘못된 노드 생성 방지.
- 포맷을 전수 나열하지 않고 "표 구조 + 패턴" 으로 판정하므로 새 포맷에도 견고. 엄격 모드라 비정형은 일단 차단(추후 ③ 포맷 프로파일로 "확인 후 허용" 완화 여지).
- 검증: `classifyFormat` 단위 8/8, E2E 14/14(번호형 등록 가능 / 형식 오류 등록 불가, 깊이형 시리즈 묶음 포함).

## 대안

- **경고 후 등록 허용(느슨)** / **주의 구분 없이 전부 허용** — 사용자가 **엄격(주의도 차단)** 선택.
