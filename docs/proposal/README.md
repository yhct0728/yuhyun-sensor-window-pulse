# Pulse 프로젝트 안내 자료 — 유현건설

> **Pulse 데스크톱 프로그램**의 현재 상태와 앞으로의 작업을 정리한 자료입니다.
> 정식 계약서 / 견적서의 부속 자료로 함께 보시면 됩니다.

---

## 📌 한 줄 소개

**Pulse는 유현건설 사무실 PC에서 동작하며, 현장 센서 측정값(메모장 파일)을
자동으로 읽어 회사 서버로 전송하고, 실시간 모니터링 화면을 제공하는 프로그램입니다.**

(카카오톡 PC 버전처럼 설치해서 쓰는 데스크톱 프로그램입니다.)

## 읽으시는 순서 추천

1. **빠르게 파악하고 싶으시면** → `01 프로젝트 현황` 만 보셔도 전체 그림이 잡힙니다.
2. **무엇을 만들지 궁금하시면** → `02 작업 범위` + `05 일정`
3. **실제로 어떻게 쓰는지 보고 싶으시면** → `04 사용 시나리오` + `06 화면 미리보기`
4. **기술이 믿을 만한지 궁금하시면** → `03 기술 스택`

---

## 핵심 요약 (3줄)

1. 직원이 **수동으로 하던 데이터 정리·전송 작업을 Pulse가 자동으로** 대신합니다.
2. **직원이 보는 화면은 거의 완성**되었고, 이제 자동화·저장·로그인 등 핵심 기능을 완성합니다.
3. **Slack·VS Code·노션과 같은 검증된 표준 기술**로 만들어져 안정적입니다.
