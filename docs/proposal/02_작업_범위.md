# 02. 작업 범위 — 정식 계약에서 만들 기능들

> 각 기능을 ① 어떤 기능인지 ② 직원분이 어떻게 사용하는지 ③ 어떤 효과가 있는지 로 정리했습니다.

---

## 1. 데이터 영구 저장

### 기능

PC를 껐다 켜도 **등록한 장비 정보와 측정값이 그대로 유지**됩니다.

### 어떻게 동작하나요?

- 직원이 등록한 장비, 설정, 수집한 측정값이 **PC 안에 안전하게 저장**됩니다.
- 컴퓨터를 끄거나 프로그램을 닫았다 다시 열어도 **어제 하던 그대로** 이어집니다.
- (지금은 프로그램을 끄면 정보가 사라져서 매번 다시 등록해야 합니다 — 이 부분을 해결합니다.)

### 가치

- 매일 아침 장비를 다시 등록하는 번거로움이 사라집니다.
- 그동안 쌓인 측정값을 **누적해서 그래프로** 볼 수 있습니다.
- 정전이나 PC 재부팅에도 데이터가 안전합니다.

---

## 2. 메모장 파일 자동 감지

### 기능

사무실 PC의 지정 폴더에 **새 메모장 파일이 추가되면 Pulse가 자동으로 발견**하여 알려드립니다.

### 어떻게 동작하나요?

1. 직원이 지정 폴더(예: `C:\geolink-data`)를 한 번 설정해 둡니다.
2. Pulse가 **매 30분마다 자동으로** 폴더를 확인합니다.
3. 새 파일을 발견하면 화면 상단에 **"등록되지 않은 파일 N개 발견"** 으로 표시합니다.
4. 직원이 확인 후 **[등록]** 버튼으로 정식 등록합니다.

### 가치

- 직원이 일일이 폴더를 열어볼 필요가 없습니다.
- 새 파일이 **누락될 위험이 없습니다.**
- 확인에 드는 시간이 절약됩니다.

---

## 3. 측정값 자동 분석 (메모장 내용 읽기)

### 기능

메모장 파일 안의 숫자들을 Pulse가 **자동으로 읽고 해석**합니다.

### 어떻게 동작하나요?

- 메모장에는 시간과 측정값이 표 형태로 들어 있습니다.
- Pulse가 이 표를 자동으로 읽어 **"이건 센서 몇 개짜리이고, 각 열이 무슨 값인지"** 를 파악합니다.
- 직원은 숫자를 직접 읽거나 입력할 필요가 없습니다.

### 가치

- 사람이 메모장을 해석하다 생기는 **실수가 없습니다.**
- 센서가 수십 개여도 **순식간에 정리**됩니다.

---

## 4. 백엔드로 자동 전송 (1시간마다)

### 기능

읽어들인 측정값을 **정해진 주기마다 회사 서버로 자동 전송**합니다.

### 어떻게 동작하나요?

1. Pulse가 새로 들어온 측정값을 모읍니다.
2. **약 1시간마다** 회사 백엔드 서버로 자동 전송합니다. (주기는 조정 가능)
3. 직원은 아무것도 누르지 않아도 됩니다.

### 가치

- 데이터가 **빠짐없이 서버에 쌓입니다.**
- 보고서를 위해 수동으로 옮겨 적을 필요가 없습니다.
- 웹에서 누구나 최신 데이터를 볼 수 있게 됩니다.

---

## 5. 로그인 시스템

### 기능

**아이디와 비밀번호**로 본인 확인 후 프로그램을 사용합니다.

### 어떻게 동작하나요?

1. Pulse를 켜면 먼저 **로그인 화면**이 나옵니다.
2. 직원이 본인 아이디/비밀번호를 입력합니다.
3. 확인되면 모니터링 화면으로 들어갑니다.

### 가치

- 허가받은 직원만 데이터에 접근할 수 있어 **보안이 강화**됩니다.
- 누가 어떤 작업을 했는지 관리할 수 있는 기반이 됩니다.

---

## 6. 권한별 화면 표시 (관리자 / 일반)

### 기능

직원의 **역할에 따라 보이는 화면과 가능한 작업을 다르게** 합니다.

### 어떻게 동작하나요?

- **관리자**: 모든 장비 관리, 삭제, 설정 변경 등 전체 권한
- **일반 직원**: 모니터링과 일상 등록 위주의 화면

### 가치

- 실수로 중요한 설정이 바뀌는 일을 방지합니다.
- 역할에 맞는 **깔끔한 화면**으로 혼란을 줄입니다.

---

## 7. 알림 (현장 추가, 데이터 오류 등)

### 기능

중요한 일이 생기면 **화면에서 바로 알려드립니다.**

### 어떻게 동작하나요?

- 새 현장/장비가 추가되었을 때
- 데이터에 이상이 의심될 때 (값이 갑자기 튀거나, 한동안 데이터가 안 들어올 때)
- 서버 전송에 문제가 생겼을 때

→ 화면에 알림으로 표시해 직원이 바로 대응할 수 있게 합니다.

### 가치

- 문제를 **빨리 발견**해 큰 사고를 예방합니다.
- 직원이 계속 들여다보지 않아도 됩니다.

---

## 8. 다크 모드  ✅ (이미 완성)

### 기능

화면을 **어두운 색조**로 바꿔 눈의 피로를 줄입니다.

### 어떻게 동작하나요?

- 버튼 하나로 밝은 화면 ↔ 어두운 화면을 전환합니다.
- 한 번 설정하면 다음에 켜도 유지됩니다.

### 가치

- 오래 모니터링하는 직원의 **눈 피로를 줄입니다.**
- (이 기능은 이미 완성되어 바로 사용 가능합니다.)

---

## 9. 오프라인 대응 (인터넷 끊겨도 데이터 보존)

### 기능

인터넷이 끊기거나 서버에 문제가 있어도 **측정값을 잃지 않습니다.**

### 어떻게 동작하나요?

1. 전송 중 인터넷이 끊기면, 못 보낸 데이터를 **PC에 안전하게 보관**합니다.
2. 인터넷이 복구되면 **보관해 둔 데이터를 자동으로 다시 전송**합니다.
3. 중복 없이, 누락 없이 채워집니다.

### 가치

- 네트워크 사정과 상관없이 **데이터가 100% 보존**됩니다.
- 직원이 신경 쓰지 않아도 알아서 복구합니다.
