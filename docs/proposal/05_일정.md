# 05. 일정 — 언제, 무엇을 완성하나요?

> 아래 일정은 **제안 기준**이며, 계약 협의 시 조정될 수 있습니다.
> 날짜 대신 **"계약 후 N주차"** 로 표기했습니다.

---

## 전체 프로젝트는 3개의 축으로 이루어집니다

유현건설 계측 시스템은 크게 세 부분이 맞물려 돌아갑니다.

| 축 | 역할 | 비유 |
|---|---|---|
| **① Pulse (본 문서)** | 사무실 PC에서 데이터를 모아 서버로 전송 | 데이터를 모으는 **수집가** |
| **② 백엔드 서버** | 데이터를 저장·정리·관리 | 데이터를 보관하는 **창고** |
| **③ 웹 화면** | 저장된 데이터를 보기 좋게 표시 | 데이터를 보여주는 **전광판** |

> Pulse는 이 중 **①번**입니다. ②③과 정해진 규칙(데이터를 주고받는 약속)으로 연결됩니다.

---

## Pulse 주차별 마일스톤 (제안)

### ✅ 0주차 — 이미 완료된 부분 (계약 전)

- 직원이 보는 **모든 주요 화면** 제작 완료
- 서버로 보내는 **전송 통로** 연결 완료
- 자동 품질검사 44건 통과

---

### 🚧 1~2주차 — 데이터 영구 저장 + 기반 다지기

| 목표 | 직원이 체감하는 변화 |
|---|---|
| PC에 데이터 영구 저장 (SQLite 도입) | 껐다 켜도 장비·측정값 그대로 유지 |
| 등록 정보 보존 | 매일 다시 등록할 필요 없음 |

**마일스톤**: "PC를 재부팅해도 어제 데이터가 그대로 보입니다."

---

### 🚧 3~4주차 — 자동화 엔진 (감지 · 분석 · 전송)

| 목표 | 직원이 체감하는 변화 |
|---|---|
| 폴더 자동 감지 (30분 주기) | 새 파일을 알아서 발견 |
| 측정값 자동 분석 | 메모장을 사람이 읽을 필요 없음 |
| 백엔드 자동 전송 (1시간 주기) | 손대지 않아도 서버에 데이터가 쌓임 |

**마일스톤**: "직원이 아무 버튼도 누르지 않아도 데이터가 서버로 흘러갑니다."
**연동 시점**: 이 단계에서 **백엔드 서버와 본격 연동 테스트**를 진행합니다.

---

### 🚧 5~6주차 — 안정성 (오프라인 대응 + 알림)

| 목표 | 직원이 체감하는 변화 |
|---|---|
| 오프라인 대응 | 인터넷이 끊겨도 데이터 보존·자동 재전송 |
| 알림 기능 | 데이터 이상·미수신을 화면에서 바로 안내 |

**마일스톤**: "네트워크가 불안정해도 데이터가 안 사라지고, 문제가 생기면 먼저 알려줍니다."

---

### 🚧 7~8주차 — 계정 · 권한 + 마무리

| 목표 | 직원이 체감하는 변화 |
|---|---|
| 로그인 시스템 | 허가된 직원만 접속 |
| 권한별 화면 (관리자/일반) | 역할에 맞는 화면 |
| 전체 안정화·검수 | 실사용 환경에서 최종 점검 |

**마일스톤**: "실제 직원 계정으로 로그인해 안전하게 사용합니다."
**연동 시점**: 로그인은 **백엔드 계정 시스템과 연동**합니다.

---

## 한눈에 보는 일정표

```
주차      1    2    3    4    5    6    7    8
        ├────┼────┼────┼────┼────┼────┼────┼────┤
저장     ████████
자동화             ████████
안정성                      ████████
계정·권한                            ████████
연동테스트          ▲백엔드           ▲백엔드(계정)
```

> ▲ = 다른 팀(백엔드/웹)과 맞춰야 하는 연동 시점

---

## 다른 축과의 연동 시점 정리

| 연동 상대 | 시점 | 내용 |
|---|---|---|
| **백엔드 서버** | 3~4주차 | 측정값 자동 전송 규칙 맞추기 (이미 통로는 연결됨) |
| **백엔드 서버** | 7~8주차 | 로그인·계정 시스템 연동 |
| **웹 화면** | 4주차 이후 | Pulse가 보낸 데이터가 웹에 잘 표시되는지 확인 |

## 참고

- 위 일정은 **Pulse 단독 작업 기준**이며, 백엔드/웹 일정과 맞물려 일부 조정될 수 있습니다.
- 각 주차 종료 시 **중간 결과를 공유**드려, 진행 상황을 함께 확인하실 수 있습니다.
