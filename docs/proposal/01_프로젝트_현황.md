# 01. 프로젝트 현황 — Pulse 데스크톱 프로그램

> 유현건설 계측 모니터링 시스템 · 정식 계약 부속 자료
> 작성일: 2026년 6월

---

## 📌 Pulse가 뭔가요?

**유현건설 직원분들이 사무실 PC에서 사용하시는 데스크톱 프로그램입니다.**
(카카오톡 PC 버전이나 Slack처럼, Windows에서 실행되는 프로그램입니다.)

### 하는 일

1. **현장에서 들어오는 센서 측정값(메모장 파일)을 자동으로 읽어옵니다.**
2. **측정값을 회사 백엔드 서버로 자동 전송합니다.**
3. **실시간 모니터링 화면을 제공합니다.**

### 한마디로 비유하면

> 직원이 매일 수동으로 메모장을 열어 데이터를 입력하고 보고서를 정리하는 일을,
> **Pulse가 24시간 자동으로 대신 해드립니다.**

---

## 왜 이 프로그램이 필요한가요?

현장에 설치된 센서(수위계, 지중경사계 등)는 측정값을 **메모장 파일(.txt)** 형태로
사무실 PC에 계속 쌓아둡니다. 지금까지는 이 파일들을 사람이 직접 열어보고,
값을 확인하고, 정리해서 보고해야 했습니다.

**Pulse는 이 과정을 통째로 자동화합니다.**

| 구분 | Pulse 도입 전 | Pulse 도입 후 |
|---|---|---|
| 파일 확인 | 직원이 폴더를 일일이 열어봄 | 프로그램이 자동으로 발견 |
| 값 읽기 | 메모장을 직접 읽고 해석 | 자동으로 읽어 화면에 정리 |
| 서버 전송 | 수동 입력 / 누락 위험 | 정해진 주기마다 자동 전송 |
| 모니터링 | 그때그때 파일을 봐야 함 | 한 화면에서 전체 현황 파악 |

---

## 지금 어디까지 만들어졌나요?

Pulse는 **눈에 보이는 화면(사용자 인터페이스)이 거의 완성된 단계**입니다.
직원분이 실제로 보고 누르는 화면들은 대부분 동작하며, 이제 그 뒤에서 자동으로
움직이는 "자동화 엔진"과 "안전 장치"를 채워 넣는 작업이 정식 계약의 핵심입니다.

### 이미 완성된 부분 ✅

| 화면 / 기능 | 상태 | 설명 |
|---|---|---|
| **모니터링 화면** | ✅ 완료 | 전체 센서 장비(노드)의 상태를 한눈에 보는 메인 화면 |
| **파일 감지·등록 화면** | ✅ 완료 | 새로 들어온 메모장 파일을 보여주고 등록하는 화면 |
| **장비 등록 마법사** | ✅ 완료 | 파일을 분석해 어떤 센서인지 자동 파악하고 등록 |
| **장비 상세 화면** | ✅ 완료 | 특정 장비의 측정값 흐름·전송 내역을 보는 화면 |
| **전송 현황 화면** | ✅ 완료 | 서버로 보낸 데이터의 전송 상태를 보는 화면 |
| **계측기 도감** | ✅ 완료 | 센서 종류별 설명을 모아둔 참고 사전 화면 |
| **설정 화면** | ✅ 완료 | 감시할 폴더, 서버 연결 정보를 지정하는 화면 |
| **다크 모드** | ✅ 완료 | 눈이 편한 어두운 화면 모드 (낮/밤 전환) |
| **서버 자동 전송 연결** | ✅ 완료 | 측정값을 회사 서버로 보내는 통로가 연결됨 |
| **친절한 안내 팝업** | ✅ 완료 | 처음 쓰는 분을 위한 단계별 사용 안내 |

### 앞으로 채울 부분 🚧 (정식 계약 작업)

| 기능 | 상태 | 한 줄 설명 |
|---|---|---|
| **데이터 영구 저장** | 🚧 예정 | PC를 껐다 켜도 정보가 그대로 유지되게 |
| **파일 자동 감지** | 🚧 예정 | 직원이 확인 안 해도 새 파일을 자동 발견 |
| **측정값 자동 분석·전송** | 🚧 예정 | 정해진 주기마다 알아서 읽고 보내기 |
| **로그인 시스템** | 🚧 예정 | 아이디/비밀번호로 안전하게 접속 |
| **권한별 화면** | 🚧 예정 | 관리자/일반 직원에 따라 보이는 화면 구분 |
| **알림 기능** | 🚧 예정 | 새 현장 추가·데이터 이상 시 알려주기 |
| **오프라인 대응** | 🚧 예정 | 인터넷이 끊겨도 데이터를 잃지 않게 |

> 자세한 작업 내용은 **[02. 작업 범위](02_작업_범위.md)** 에 정리되어 있습니다.

## 전체 진행률 (쉽게 보기)

```
화면(직원이 보는 부분)      ▓▓▓▓▓▓▓▓▓▓  거의 완성
서버 연결(전송 통로)         ▓▓▓▓▓▓▓▓░░  연결 완료, 자동화 보강 예정
자동화 엔진(알아서 동작)     ▓▓▓░░░░░░░  정식 계약에서 본격 진행
계정·권한·알림              ▓░░░░░░░░░  정식 계약에서 신규 제작
```

쉽게 말씀드리면 — **"보여지는 집은 거의 다 지어졌고, 이제 그 안에 전기·수도·보일러
(자동화·저장·보안)를 넣는 단계"** 라고 이해하시면 됩니다.

---

## 어디서, 어떻게 동작하나요?

| 항목 | 내용 |
|---|---|
| **실행 환경** | 사무실 Windows PC (윈도우 10/11) |
| **프로그램 형태** | 설치형 데스크톱 앱 (카카오톡 PC 버전처럼 설치해서 사용) |
| **사용 장소** | 유현건설 사무실 — 센서 파일이 모이는 PC |
| **인터넷** | 서버 전송 시 필요 (끊겨도 데이터는 보존 예정) |
| **사용 대상** | 유현건설 직원 (현장 데이터를 관리하는 담당자) |

---

## 정리

- Pulse는 **현장 센서 데이터를 자동으로 읽어 서버로 보내고, 화면으로 보여주는** 사무실 PC 프로그램입니다.
- **직원이 보는 화면은 거의 완성**되었습니다.
- 정식 계약을 통해 **자동화·데이터 저장·로그인·알림** 등 핵심 기능을 완성합니다.
