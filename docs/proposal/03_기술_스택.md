# 03. 기술 스택 — 어떤 기술로 만들어졌나요?

> 어려운 용어 없이, "이게 무슨 도구이고 어떤 회사들이 같이 쓰는지" 위주로 정리했습니다.

---

## 들어가기 전에

Pulse는 **새롭거나 실험적인 기술이 아니라, 전 세계 유명 회사들이 쓰는 검증된 표준 기술**로
만들어졌습니다. 즉, 안정적이고 오래 유지보수할 수 있습니다.

---

## 이 프로그램은 다음 유명 프로그램들과 같은 기술로 만들어졌습니다

| 유명 프로그램 | 같은 기술 |
|---|---|
| **Slack** (업무용 메신저) | Electron |
| **Visual Studio Code** (개발 도구) | Electron |
| **Discord** (게이밍 메신저) | Electron |
| **노션 Notion** (메모·문서) | Electron |

> 즉, **검증되고 안정적인 표준 기술**로 만들어졌습니다.
> 매일 수천만 명이 쓰는 프로그램들과 **같은 뼈대**라고 보시면 됩니다.

---

## 사용 기술 자세히 보기

### 1. Electron (일렉트론)

| 항목 | 내용 |
|---|---|
| **무엇을 하는 도구인가** | Windows·Mac PC에서 실행되는 **데스크톱 프로그램을 만드는 도구** |
| **같이 쓰는 회사** | Slack, Microsoft(VS Code), Discord, Notion |
| **왜 이걸 쓰는가** | 카카오톡 PC 버전 같은 **설치형 앱**을 안정적으로 만들 수 있고, 전 세계적으로 검증됨 |

쉽게 말해 — **"프로그램의 창과 몸체를 만드는 뼈대"** 입니다.

---

### 2. React (리액트)

| 항목 | 내용 |
|---|---|
| **무엇을 하는 도구인가** | 직원분이 보는 **화면(버튼·표·그래프 등)을 만드는 도구** |
| **같이 쓰는 회사** | 페이스북(메타), 인스타그램, 넷플릭스, 에어비앤비 |
| **왜 이걸 쓰는가** | 세계에서 가장 많이 쓰이는 화면 제작 도구라 **안정적이고 유지보수 인력 구하기 쉬움** |

쉽게 말해 — **"눈에 보이는 화면을 그리는 도구"** 입니다.

---

### 3. SQLite (에스큐엘라이트) — 도입 예정

| 항목 | 내용 |
|---|---|
| **무엇을 하는 도구인가** | **PC 안에 데이터를 안전하게 저장**하는 작은 데이터베이스 |
| **같이 쓰는 회사** | 애플(아이폰), 구글(안드로이드), 모든 스마트폰에 기본 탑재 |
| **왜 이걸 쓰는가** | 별도 서버 없이 **PC 한 대 안에서 데이터를 안정적으로 보관**할 수 있음. 전 세계에서 가장 널리 쓰이는 저장 방식 |

쉽게 말해 — **"PC를 껐다 켜도 데이터가 남아있게 해주는 안전 금고"** 입니다.
(여러분 스마트폰 안에서도 똑같은 기술이 쓰이고 있습니다.)

---

### 4. Tailwind CSS (테일윈드) ✅

| 항목 | 내용 |
|---|---|
| **무엇을 하는 도구인가** | 화면을 **깔끔하고 보기 좋게 꾸미는 디자인 도구** |
| **같이 쓰는 회사** | OpenAI(ChatGPT), GitHub, 셸·스타트업 다수 |
| **왜 이걸 쓰는가** | 빠르게 **일관된 디자인**을 적용할 수 있어 화면이 정돈되어 보임 |

쉽게 말해 — **"화면을 단정하게 꾸미는 옷"** 입니다.

---

### 5. Vite (비트) ✅

| 항목 | 내용 |
|---|---|
| **무엇을 하는 도구인가** | 프로그램을 **빠르게 조립·빌드하는 도구** (개발 속도를 높임) |
| **같이 쓰는 회사** | 구글, 셸·웹 개발 업계 표준으로 빠르게 확산 중 |
| **왜 이걸 쓰는가** | 개발이 빠르고, **설치 파일을 효율적으로 만들 수 있음** |

쉽게 말해 — **"부품을 빠르게 조립해 완제품으로 만드는 공장 설비"** 입니다.

---

### 6. Playwright (플레이라이트) ✅

| 항목 | 내용 |
|---|---|
| **무엇을 하는 도구인가** | 프로그램이 **제대로 동작하는지 자동으로 검사**하는 품질 점검 도구 |
| **같이 쓰는 회사** | 마이크로소프트(제작사), 다수 IT 기업 |
| **왜 이걸 쓰는가** | 사람이 일일이 확인하지 않아도 **버그를 자동으로 잡아내** 품질을 보장 |

쉽게 말해 — **"출고 전 자동 품질 검사관"** 입니다.
(현재 Pulse는 44개의 자동 검사를 모두 통과한 상태로 관리되고 있습니다.)

---

## 정리

| 기술 | 역할 | 한 줄 요약 |
|---|---|---|
| Electron | 프로그램 뼈대 | Slack·VS Code와 같은 도구 |
| React | 화면 제작 | 페이스북·넷플릭스와 같은 도구 |
| SQLite | 데이터 저장 | 모든 스마트폰에 들어있는 저장 기술 |
| Tailwind CSS | 화면 디자인 | ChatGPT·GitHub와 같은 도구 |
| Vite | 조립·빌드 | 빠른 제작 공장 설비 |
| Playwright | 자동 품질검사 | 출고 전 검사관 |

> **핵심**: Pulse는 전 세계 대형 IT 기업들이 신뢰하고 쓰는 **검증된 표준 기술**로
> 만들어졌습니다. 특정 개인만 다룰 수 있는 특이한 기술이 아니라, 안정적이고
> 오래 유지보수할 수 있는 구조입니다.
