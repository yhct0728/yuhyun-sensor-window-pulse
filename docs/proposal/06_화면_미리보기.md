# 06. 화면 미리보기 — 어떤 화면들이 있나요?

> 현재 만들어진 화면들을 소개합니다.
> 스크린샷은 `[ 📷 스크린샷 자리 ]` 표시 부분에 추후 첨부해 주시면 됩니다.
> (✅ = 현재 완성 / 🚧 = 정식 계약에서 제작 예정)

---

## 1. 로그인 화면  🚧 (제작 예정)

```
[ 📷 스크린샷 자리 — 로그인 화면 ]
```

- **무엇을 보는 화면인가**: Pulse를 켜면 가장 먼저 나오는 본인 확인 화면
- **어떤 동작을 할 수 있나**: 아이디/비밀번호 입력 후 접속
- **상태**: 정식 계약 작업으로 제작 예정 (회사 계정 시스템과 연동)

---

## 2. 모니터링 화면 (대시보드)  ✅

```
[ 📷 스크린샷 자리 — 모니터링 화면 (밝은 모드) ]
```

- **무엇을 보는 화면인가**: 전체 센서 장비(노드)의 상태를 **한눈에** 보는 메인 화면
- **어떤 동작을 할 수 있나**:
  - 전체 장비를 카드/표/간단 보기 3가지 방식으로 보기
  - 정상(초록)·지연(노랑) 등 상태별로 한눈에 구분
  - 검색·정렬·필터로 원하는 장비 빠르게 찾기
  - 새로 들어온 파일이 있으면 상단에 안내
- **상태**: ✅ 완성

---

## 3. 파일 감지 · 장비 등록 화면  ✅

```
[ 📷 스크린샷 자리 — 감지·등록 탭 ]
```

- **무엇을 보는 화면인가**: 새로 들어온 메모장 파일을 보여주고 등록하는 화면
- **어떤 동작을 할 수 있나**:
  - 감시 폴더에 들어온 파일 목록 확인
  - 아직 등록 안 된 파일을 구분해서 표시
  - 파일을 골라 등록 시작
- **상태**: ✅ 완성

---

## 4. 장비 등록 마법사 (등록 모달)  ✅

```
[ 📷 스크린샷 자리 — 등록 마법사 3단계 ]
```

- **무엇을 보는 화면인가**: 파일을 분석해 장비로 등록하는 **단계별 안내 창**
- **어떤 동작을 할 수 있나**:
  - **1단계(분석)**: Pulse가 파일을 읽어 "센서 몇 개짜리인지" 자동 파악
  - **2단계(채널 매핑)**: 장비 이름·계측기 종류 확인 (자동으로 채워줌)
  - **3단계(확인)**: 최종 내용 확인 후 등록 완료
- **상태**: ✅ 완성

---

## 5. 장비 상세 화면 (측정값 그래프)  ✅

```
[ 📷 스크린샷 자리 — 장비 상세 + 그래프 ]
```

- **무엇을 보는 화면인가**: 특정 장비 하나의 **측정값 흐름과 전송 내역**을 자세히 보는 화면
- **어떤 동작을 할 수 있나**:
  - 측정값을 그래프(차트)로 확인
  - 기간(7일/30일 등)별로 보기
  - 서버 전송 내역·상태 확인
  - 센서별 상세 정보 보기
- **상태**: ✅ 화면 완성 (실데이터 연결 고도화는 정식 계약 작업에서 진행)

---

## 6. 전송 현황 화면  ✅

```
[ 📷 스크린샷 자리 — 전송 큐 ]
```

- **무엇을 보는 화면인가**: 서버로 보낸 데이터의 **전송 상태**를 모아 보는 화면
- **어떤 동작을 할 수 있나**:
  - 전송 완료/대기/실패 상태 확인
  - 문제가 있는 항목 우선 표시
  - 다시 전송하기
- **상태**: ✅ 완성

---

## 7. 계측기 도감  ✅

```
[ 📷 스크린샷 자리 — 계측기 도감 ]
```

- **무엇을 보는 화면인가**: 센서 종류(수위계·지중경사계 등)별 설명을 모은 **참고 사전**
- **어떤 동작을 할 수 있나**: 계측기 종류·카테고리별로 정보 열람 (읽기 전용)
- **상태**: ✅ 완성

---

## 8. 설정 화면  ✅

```
[ 📷 스크린샷 자리 — 설정 화면 ]
```

- **무엇을 보는 화면인가**: Pulse의 동작 환경을 지정하는 화면
- **어떤 동작을 할 수 있나**:
  - 감시할 폴더 지정 (센서 파일이 모이는 위치)
  - 회사 서버 연결 정보 입력
  - 폴더 상태 확인
- **상태**: ✅ 완성

---

## 9. 다크 모드  ✅

```
[ 📷 스크린샷 자리 — 같은 화면의 어두운 모드 ]
```

- **무엇을 보는 화면인가**: 모든 화면을 **어두운 색조**로 바꾼 모드
- **어떤 동작을 할 수 있나**: 버튼 하나로 밝은 화면 ↔ 어두운 화면 전환 (설정 유지)
- **상태**: ✅ 완성
