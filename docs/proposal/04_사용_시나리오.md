# 04. 사용 시나리오 — 직원분이 실제로 이렇게 사용합니다

> 정식 계약 작업이 모두 완료되었을 때, 직원분이 하루를 어떻게 보내는지
> **실제 사무실 상황**으로 그려보았습니다.
> (일부 단계는 현재 제작 중인 기능을 포함한 **완성 후 모습**입니다 — 표시: 🚧)

---

## 시나리오 ① 새 직원이 처음 Pulse를 사용하는 날

```
[09:00] 직원이 사무실 PC에서 Pulse 실행
   → 로그인 화면 표시  🚧
   → 본인 ID / 비밀번호 입력

[09:01] 모니터링 화면(대시보드) 진입
   → 화면 상단에 "등록되지 않은 파일 3개 발견" 알림 표시

[09:03] 새 장비(노드) 등록
   → 감지된 메모장 파일을 선택
   → Pulse가 파일을 자동 분석 ("센서 21개짜리 번호형 파일입니다")
   → 장비 이름·계측기 종류 확인 (자동으로 채워줌, 필요 시 수정)
   → [등록 완료] 클릭

[09:05] 장비 카드가 화면에 표시됨
   → 측정값 자동 수집 시작
   → 30분마다 자동으로 새 데이터를 가져옴  🚧

[10:00] 1시간 후, 측정값이 회사 서버로 자동 전송됨  🚧
   → 직원은 아무것도 안 해도 됨

[익일] 직원이 다시 Pulse 실행
   → 어제 등록한 장비 정보가 그대로 유지됨  🚧
   → 측정값이 누적된 그래프 확인 가능
```

**핵심**: 처음 한 번만 등록하면, 그다음부터는 **직원이 손대지 않아도 알아서 돌아갑니다.**

---

## 시나리오 ② 평소 일상 모니터링

```
[출근 후] Pulse를 켜두기만 함
   → 모니터링 화면에 모든 장비가 카드로 한눈에 표시
   → 정상인 장비는 초록색, 데이터가 늦는 장비는 노란색으로 구분

[수시로] 직원이 화면을 슬쩍 확인
   → "전체 장비 12개 중 11개 정상 수신 중"
   → 특정 장비가 궁금하면 카드를 눌러 상세 화면으로
   → 측정값 흐름을 그래프로 확인

[하루 종일] Pulse는 백그라운드에서 계속 동작
   → 새 데이터 자동 수집 → 서버 자동 전송  🚧
   → 직원은 다른 업무를 봐도 됨
```

**핵심**: 모니터링은 **"가끔 흘끔 보는 것"** 으로 충분합니다. 나머지는 Pulse가 합니다.

---

## 시나리오 ③ 데이터 이상 알림이 떴을 때  🚧

```
[14:30] 화면 우측에 알림 표시
   → "⚠️ 7번 장비, 2시간째 데이터가 들어오지 않습니다"

[14:31] 직원이 알림을 클릭
   → 해당 장비 상세 화면으로 바로 이동
   → "마지막 수신: 2시간 전" 확인

[14:32] 직원이 현장에 연락
   → 센서 또는 현장 PC 점검 요청
   → (Pulse는 '무엇이 이상한지'를 빨리 알려주는 역할)

[15:00] 현장 조치 후 데이터 재개
   → 알림이 자동으로 사라지고 초록색으로 복귀
```

**핵심**: 문제를 **사람이 뒤늦게 발견하는 게 아니라, Pulse가 먼저 알려줍니다.**

---

## 시나리오 ④ 인터넷이 끊겼다가 복구되는 경우  🚧

```
[11:00] 사무실 인터넷 일시 장애
   → 서버로 전송이 일시 중단됨
   → Pulse는 못 보낸 데이터를 PC에 안전하게 보관
   → 화면에는 "전송 대기 중 N건" 으로 표시

[11:00~11:40] 인터넷 끊긴 동안에도
   → 측정값 수집은 계속됨 (메모장 파일은 PC에 쌓이므로)
   → 데이터 손실 없음

[11:40] 인터넷 복구
   → 보관해 둔 데이터를 Pulse가 자동으로 다시 전송
   → 중복 없이, 빠짐없이 서버에 채워짐
   → "전송 대기 중" 표시가 사라짐
```

**핵심**: 네트워크가 불안정해도 **데이터는 단 한 건도 잃지 않습니다.**

---

## 시나리오 ⑤ 서버에 쌓인 데이터를 웹에서 확인

```
[수시로] 관리자나 본사에서
   → Pulse가 보낸 데이터는 회사 백엔드 서버에 차곡차곡 쌓임
   → 웹 모니터링 화면(별도 시스템)에서 누구나 최신 현황 열람

[보고 시] 별도 정리 작업 없이
   → 이미 서버에 데이터가 다 있으므로
   → 그래프·표를 바로 활용해 보고
```

**핵심**: Pulse(사무실 PC)가 보낸 데이터를 **웹에서 언제 어디서나** 볼 수 있습니다.
(Pulse는 "데이터를 모아 서버로 올리는 역할", 웹은 "올라온 데이터를 보여주는 역할"로 나뉩니다.)

---

## 전체 그림 — Pulse는 이 흐름의 어디에 있나요?

```
   현장 센서            사무실 PC               회사 서버           웹 화면
  (수위계 등)    →    [ Pulse 프로그램 ]   →   (백엔드)      →   (모니터링)
                       ─────────────
   측정값을           ① 파일 자동 감지         데이터 보관       누구나
   메모장으로         ② 측정값 자동 분석        & 관리           열람 가능
   계속 저장          ③ 서버로 자동 전송
```

> **Pulse = 현장과 서버를 잇는 "자동 다리"** 입니다.
> 직원분의 손이 가던 일을 Pulse가 대신 건너게 해줍니다.
