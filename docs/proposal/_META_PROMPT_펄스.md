# 메타 프롬프트 — Pulse 설명서 + 견적서 생성 (이 한 장이면 끝)

> **이게 LLM에 던질 단 하나의 파일이다.** Pulse(현장 PC 수집기) 트랙 **단독**.
> 사용법: 새 채팅 열고 → 이 프롬프트 전체 붙여넣고 → 아래 `[단가]` 한 줄만 채우면 → **설명서 + 견적서(금액 포함)** 가 나온다.
> 자기완결 — 다른 파일 없이 이 문서만으로 Pulse 전체 파악·견적 가능. (더 깊은 근거가 필요하면 같은 폴더의 `00_견적용_기술총정리.md` 참조)

---

## [단가] — 이 줄만 채우세요 (비우면 금액 보류, 추측 금지)

```
통화 = KRW
1일 단가 = (예: 400,000원/일)        ← 채우세요
복잡도→일수(중앙값): S=1.5일 / M=4일 / L=7.5일 / XL=15일
PM/QA = 개발 소계의 (예: 15%)  또는 "없음"
부가세 = 별도 / 포함
```

---

## 역할

당신은 Pulse 데스크톱 앱의 시니어 엔지니어 겸 견적 담당이다.
아래 **사실 블록만 근거로** ① 비전공자(유현건설 사장님)용 **설명서**와 ② **견적서(금액)** 를 만든다.
**추측 금지** — 블록에 없는 기능을 지어내지 말 것. **완료된 것은 견적에서 제외**, 🚧 잔여만 금액 대상.

## 사실 블록 (이 내용만 사용)

### 제품
- **Pulse** = 유현건설 계측 모니터링의 **현장/사무실 PC 수집기**. Windows 설치형 데스크톱 앱(Electron, Slack/VS Code와 같은 형태).
- **하는 일**: 타사 로거가 사무실 PC에 떨궈주는 센서 측정 `.txt`를 읽어 **검증 후 회사 서버(백엔드)로 전송** + 로컬 실시간 모니터링 화면 제공.
- **시스템 위치**: `현장 로거 → [.txt 폴더] → ★Pulse(이 견적)★ → 백엔드(별도) → 웹 프론트(별도)`. Pulse는 **노드(장비ID) 단위**로만 동작(현장 배치·품질 판정은 백엔드 몫).

### 기술 스택
- Electron 42 / React 18 / Vite 5 / Tailwind 3 / Playwright(E2E 44 통과). 차트는 자체 SVG.
- 빌드: `npm run make` → Windows 인스톨러(.exe, 약 134MB).
- **외부 상용 서비스 의존 0** (지도·분석·결제·소셜로그인 없음). 유일한 통신 = 자체 백엔드 HTTP. 폰트만 CDN(오프라인 시 시스템폰트 폴백).
- 현재 **자동 업데이트·코드서명 없음**(옵션 항목).

### 완료 ✅ (견적 제외 — 이미 구현됨)
- **화면 9종 완성**: 노드 모니터, 노드 상세 드로어(채널/큐/로그 3탭), 등록 마법사(3단계), 전송 큐, 계측기 도감, 설정, 다크모드, 온보딩, 빈 상태.
- **백엔드 전송 통로 연결**: 노드 등록(POST /nodes)·측정 전송(POST /ingest)·노드 조회(GET)·생명주기 PATCH 실연결.
- **자동 증분 전송 동작 중**: 앱이 켜져 있는 동안 60초마다 신규 행만 자동 전송.
- **품질 입력 모델**: 채널별 종류·정상범위·고장(inactive)·운영기준일·채널코드 자동 접두.
- 한계: **런타임 데이터가 메모리에만 존재 → 앱 재시작 시 휘발**, **DB 없음**, 자동 전송이 **창에 묶여 앱 닫으면 멈춤**.

### 🚧 잔여 작업 (견적 대상) — 복잡도: S=1~2일·M=3~5일·L=1~2주·XL=2주+ (개략, 보정 필요)

| ID | 작업 | 내용 | 복잡도 | 의존성 |
|---|---|---|---|---|
| R1 | 로컬 영속 저장(SQLite) | 노드/측정/큐/설정 영속화, 재시작 복원. 모든 자동화의 전제 | L | 없음 |
| R2 | 신규 파일 자동 감지 | 워치 폴더 주기 스캔으로 새 `.txt` 자동 발견 | M | 없음 |
| R3 | 측정값 파싱 고도화 | 신규 행 파싱·매핑 안정화, 인코딩/깨진 행 방어 | S~M | R2 |
| R4 | 자동 전송 워커 견고화 | 워터마크 영속화, 실패 재시도 상태머신, 주기 설정화 | S~M | R1, 백엔드 |
| R15 | 백그라운드/트레이 상주 | 창 닫아도·부팅 시 자동 무인 24시간 동작 | M | 없음 |
| R5 | 오프라인 큐 + 재전송 | 미전송분 durable 큐, 복구 시 자동 재전송, 멱등 중복 방지 | M | R1, R4 |
| R6 | 로그인 시스템 | 로그인 화면 + 토큰 보안 보관 + 세션 | M | 백엔드(계정 API) |
| R7 | 권한별 화면(RBAC) | 관리자/일반 역할 라우팅·액션 게이팅 | S~M | R6, 백엔드 |
| R8 | 알림 시스템 | 인앱 알림 + 트리거(신규파일/미수신/이상/전송실패), OS 토스트 | M | R2,R4 / 백엔드 |
| R9 | 차트 실데이터 연결 | 상세 그래프를 mock → 실측정/백엔드 조회로 교체 | S~M | R1 / 백엔드 |
| R10 | heartbeat 연동 | POST /heartbeat 생존 보고(계약 정의됨, 미연결) | S | 백엔드 |
| R13 | 통합 테스트·안정화·실배포 검수 | E2E 확장, 장기 구동 검증, 패키징 검수 | M~L | 전체 |
| R11 | 자동 업데이트(옵션) | Squirrel 자동 업데이트 피드 연결 | S~M | 배포 인프라 |
| R12 | 코드 서명(옵션) | Windows 코드서명(SmartScreen 경고 제거) | S | 인증서 비용 별도 |
| R14 | 폰트 로컬 번들링(옵션) | CDN 폰트 내장 → 외부 의존 0, 완전 오프라인 | S | 없음 |

- 권장 묶음: ①기반 R1 → ②자동화 엔진 R2·R3·R4·R15 → ③안정성 R5·R8 → ④계정 R6·R7 → ⑤마무리 R9·R10·R13 (+옵션 R11·R12·R14).
- 백엔드 의존(R4·R6·R7·R8·R9·R10)은 백엔드 일정과 맞물려 변동 → **연동 버퍼** 반영.

## 산출물 (이 순서로 2개 출력)

### ① 설명서 (비전공자용 — 친절·프로페셔널 톤, 기술용어는 일상어로)
- 한 줄 소개(카카오톡 PC처럼 설치해 쓰는 프로그램…).
- "지금까지 된 것"(화면·자동전송 통로 완성)과 "앞으로 만들 것"(영속저장·무인자동화·로그인·알림)을 쉽게.
- ❌ "RESTful API" → ✅ "회사 서버와 데이터를 주고받는 통로" 식으로 풀어쓸 것.

### ② 견적서 (금액 — [단가] 입력값만 사용)
- 잔여 작업 표: `ID / 작업 / 복잡도 / 일수 / 의존성 / 금액`. (완료 ✅ 항목은 넣지 말 것)
- 필수(R1~R10, R13)와 옵션(R11·R12·R14)을 **분리**. 옵션은 별도 라인(R12는 인증서 비용 별도 표기).
- 마일스톤 묶음별 소계 → 개발 합 → +PM/QA(%) → +연동 버퍼 → (부가세) → **최종 금액**.
- 단가 미입력이면 **일수까지만** 내고 "금액 보류" 명시.

## 체크리스트
- [ ] 설명서·견적서 2개 모두 출력
- [ ] 완료 ✅ 항목 금액 0 (제외 확인)
- [ ] 모든 잔여에 복잡도·일수·의존성·금액
- [ ] 백엔드 의존 항목에 연동 버퍼 반영
- [ ] 옵션 항목 분리, 단가는 입력값만(추측 0)
